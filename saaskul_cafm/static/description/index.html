Frequently asked questions

Is it really free?
Yes. Saaskul CAFM is free to download and use.
Which apps does it need?
Maintenance, Project, Invoicing, Sales and Saaskul Re-Sequences (free). Excel import uses the openpyxl Python library.
Can I bring my existing AMC list?
Yes. Import AMC contracts from Excel; missing clients, groups and locations are created for you. VAR work and AMC invoices also have Excel imports.
Can I try it with sample data?
Yes. Configuration → Load Demo Data fills clients, projects, units, contracts, calls, VAR and PPM. Clean Demo Data removes it again.
