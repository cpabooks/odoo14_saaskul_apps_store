# IFRS Chart of Accounts (Saaskul)

Odoo 14 store package for IFRS-style chart structure:

- **L1 Type** (1 digit): Assets, Liabilities, Equity, Income, Expense
- **L2 Group** (2 digits): IFRS reporting groups
- **L3 Ledger** (4+ digits): company-wise ledger codes
- Reset / regenerate codes with preview
- Opening balance journal with retained-earnings offset
- Merge and delete unused ledgers

Technical name: `chart_of_accounts_saaskul`

Community and Enterprise. No Enterprise module required.
