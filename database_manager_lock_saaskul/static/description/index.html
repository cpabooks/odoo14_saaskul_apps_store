Why lock it

Your login page should not offer database tools

A standard Odoo login page links to the database manager, where anyone with the master password can back up, duplicate or delete a database. Clients and staff never need it.

Standard Odoo

✗  "Manage Databases" link under every login form

When you need the manager

Unlock from the server, not from the browser

1

Add this line to the [options] section of your Odoo configuration file:

db_manager_unlock = True

2

Restart Odoo. /web/database/manager opens again for your backup or restore. The login page still hides the links.

3

Remove the line and restart Odoo to lock it again.

FAQ

Short answers

Which setups does it cover?

Servers where each domain opens one database (dbfilter), which is the usual production setup. On a server that lists many databases without a filter, also set list_db = False in odoo.conf.

Can users still log in normally?

Yes. Only the database links and the database manager URLs change. Login, password reset and sign-up work as before.

How do I take backups?

Use your server backups (pg_dump), or unlock the manager for a moment with db_manager_unlock = True.

Does it replace the master password?

No. Keep a strong master password too. This app adds a second layer by hiding and refusing the manager.
