Features

Built for contracting invoices

KIND

Labour Supply or Construction

Choose the invoice kind at the top of the customer invoice. New manual invoices start as Construction; invoices from sales orders stay normal.

WORK %

Work Done % per line

Type 30% and the line bills 30% of quantity x unit price. Taxes and the journal entry are calculated by Odoo on that amount.

PREV %

Previous % and contract amount

Record what was billed before, see the full contract amount of each line and the contract value of the invoice.

GTEE

Guarantee flag

Mark lines covered by a guarantee. The mark is printed next to the line description.

PDF

Construction Invoice print

Contract Amount, Previous %, Work Done %, amount, tax and totals on your company layout.

LOCK

Safe after posting

Work Done % and the invoice kind are locked on posted invoices. Reset to draft to change them.

The print

Construction Invoice PDF

Print it from the invoice: Print › Construction Invoice (Work Done %).

Example: a line worth 100,000 with 30% work done bills 30,000. With 5% VAT the line total is 31,500.

The standard Odoo invoice print still works and does not show the work done as a discount.

FAQ

Short answers

Does the journal entry match the work done?

Yes. Work Done % is applied through Odoo's standard line calculation, so income, VAT and receivable all use the work-done amount.

Can I still give a discount?

On Labour Supply invoices, yes. On Construction invoices the discount column is replaced by Work Done %.

Does it need other apps?

No. It depends only on Odoo's Invoicing / Accounting module.

Is Previous % calculated automatically?

No. You enter it on each progress bill. It is shown on the invoice and the print for your client.
