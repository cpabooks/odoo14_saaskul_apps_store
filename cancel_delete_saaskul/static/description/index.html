What happens behind the button

Confirmation first
Delete and Reverse open a confirmation window before anything is changed.
Payments unreconciled
Matched payments are released from the invoice before it is reset or cancelled.
History in the chatter
Each action is written to the document chatter so the team can see what changed.
Invoice lines kept
On invoices, Cancel - Lines zeroes the amounts and marks the rows, so the audit trail stays readable.
Multi-company aware
Actions run in the company of the document, even when several companies are open.
Clean form header
The actions live in one menu, so the form header does not fill up with extra buttons.

FAQ

Short answers

Does it need Enterprise?

No. It runs on Odoo 14 Community and Enterprise. All required apps are standard Community apps.

Where do I find the actions?

In list views, select a document and open the Cancel / Delete button. In the form, open the Action menu.

What about my other cancel apps?

On install, this app uninstalls these older cancel apps if they are installed: bi_order_cancel_all, dev_picking_cancel, om_mass_confirm_cancel, acc_invoice_payment_cancel_app, bi_inventory_adjustment_cancel_reverse, eq_payslip_cancel, stock_picking_cancel_extended, pos_order_cancel and cpabooks_all_cancel_extend.

Who can use it?

Every internal user gets the Cancel / Delete Global group on install, so the whole team sees the same menu.
