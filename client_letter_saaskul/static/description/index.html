FAQ

Short answers

Can I change the template text?

Yes. Open CRM › Configuration › Client Letter Templates and edit the subject, letter, email and WhatsApp text. You can also save an edited letter as a new template from the wizard.

Can I write a letter without source data?

Yes. Choose Blank Letter, or turn off Use Source Defaults, and write the letter from scratch.

Does the PDF show signature and stamp?

When the company has a stamp and the user has a signature and stamp set, they are printed on the letter.

Does it work with several companies?

Yes. The company is taken from the source document, so each letter uses that company's name and stamp.
